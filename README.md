# BOND 仕入れアプリ v1.1

`index.html` を1つ開くだけで動くWebアプリです（iPhoneのSafariとPCのブラウザに対応）。

## 使い方
1. 仕入れチャットに商品画像を送り、「取込コードを出して」と依頼します（アプリの「AIへの依頼文をコピー」で依頼文をコピーできます）。
2. 返ってきたJSONを **検索** タブに貼り付けて「取り込む」を押します。
3. 各ワードの下にあるサイトボタンから、検索結果を開きます。国内サイトは日本語ワード、海外サイトは英語ワードで検索します。
4. 気になった商品は **候補** タブに登録します。想定販売価格を入れると、利益と利益率が表示されます。
5. **設定・共有** タブからJSONファイルを書き出し、OneDrive経由で受け渡します。相手の端末で「統合」を選んで読み込みます。

## 取込コードの形式
```json
{
  "item": { "name": "", "brand": "", "category": "", "era": "", "details": "", "checkpoints": "" },
  "keywords": [ { "ja": "", "en": "", "note": "" } ],
  "design":   [ { "ja": "", "en": "", "note": "" } ],
  "similar":  [ { "ja": "", "en": "", "note": "" } ],
  "resultsMeta": "",
  "results":  [ { "site": "", "title": "", "price": "", "image": "", "url": "", "match": "" } ]
}
```
- `keywords`：同じアイテムを探すための検索語。`design`：ブランド名を使わず、デザインの特徴で探すための検索語。`similar`：似ている狙い目アイテムの検索語。
- `results`：チャット側で各サイトを実際に検索し、画像が似ている出品を選んだ結果です。画像付きの一覧で表示され、サイトごとに絞り込めます。「候補に追加」で候補タブに登録できます。
- 必要なキーだけを含む取込コードでもかまいません（例：`results` だけを取り込むと、既存のワードはそのまま残ります）。
- eBayは自動ブラウザでの閲覧がブロックされるため、`results` には含まれません（検索ボタンからは開けます）。
- 検索の手順は [SEARCH_GUIDE.md](./SEARCH_GUIDE.md) にまとめています。チャットで「仕入れ検索」と送ったときだけ検索します。結果は25件ずつで、「仕入れ検索 続き」と送ると次の25件が出ます（合計100件まで）。
- `"batch"` が2以上の取込コードは、前の結果に追加されます（同じURLは重複しません）。
- 取り込んだ内容はブラウザに保存されるので、ページを再読み込みしても残ります（「クリア」で消えます）。
- チャットは検索結果を `results/latest.json` に保存してプッシュします。アプリは開いたときにこのファイルを確認し、新しければ自動で読み込みます。「最新の検索結果を読み込む」ボタンでも読み込めます。どの端末でも同じ結果が見られます。※公開リポジトリなので、出品情報（タイトル・価格・画像URL）は誰でも見られます。
- 前後に説明文が付いていても、JSONの部分だけを取り込みます。

## 注意
- データは端末のブラウザ内（localStorage）に保存されます。こまめに書き出してください。
- 価格の絞り込みは、国内4サイト（メルカリ・ヤフオク・Yahoo!フリマ・ラクマ）だけに反映されます。
- 利益計算の初期値は、BASEの手数料（6.6%＋40円）です。設定タブで変更できます。
